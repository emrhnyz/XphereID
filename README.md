# XphereID

Human-readable **`.xp` names** on [Xphere](https://x-phere.com/) — a grant-oriented name service demo.

`alice.xp` → `0x…` on-chain. Non-custodial identity infrastructure for the Xphere ecosystem.

## Goal

Ship a working MVP on Xphere testnet + mainnet suitable for the [Xphere Grant Program](https://x-phere.com/grant.html): register, resolve, and prove it with explorer txs.
